Weekly
Report.

Manager submission portal

Area ini digunakan oleh manager dan pengurus yang telah diberi izin untuk mengumpulkan Weekly Report KSPM FEB UPNVJ.

Ketentuan pengumpulan
  • Akses upload hanya untuk manager/pengurus yang ditambahkan oleh admin Google Drive.
  • Format yang diterima: PDF, Word (.doc/.docx), dan Excel (.xls/.xlsx).
  • Gunakan nama file: Divisi_Nama_Period (contoh: CreativeMarketing_Alya_Week01.pdf).
  • Pastikan file sudah final dan dapat dibuka sebelum diunggah.
Open Manager Upload Folder ↗

Google Drive akan meminta login. Jika kamu tidak memiliki izin Editor, hubungi admin folder untuk meminta akses. Jangan membagikan akses Editor kepada seluruh anggota.
